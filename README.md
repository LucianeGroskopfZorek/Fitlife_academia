## 📋 About the Project

FitLife Academia is a front-end only website created as part of the **Web Designer** certificate program at **SENAC-SC**.

The goal was to build a complete, responsive landing page for a fictional gym — practicing real-world layout techniques, visual hierarchy, and interactive elements without any framework or library.

---

## ✨ Features

- 📱 **Fully responsive** — adapts to mobile, tablet, and desktop
- 🎨 **Custom visual identity** — original color palette and typography
- 🗓️ **Class schedule section** — displaying gym timetable
- 📬 **Contact form** — with basic front-end validation
- ✨ **CSS animations** — smooth transitions and hover effects
- 🧭 **Navigation menu** — with smooth scroll behavior
